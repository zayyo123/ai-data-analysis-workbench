# AI Data Analysis Workbench

一个面向前端简历和面试展示的 AI 数据分析工作台项目。

## 项目定位

AI Data Analysis Workbench 用来展示前端文件解析、大数据表格、图表可视化、复杂筛选、AI 流式输出和报告生成能力。

目标效果：

- 上传 CSV / Excel
- 数据字段识别
- 表格预览
- 图表自动推荐
- Dashboard 自定义编排
- 多图表联动筛选
- AI 生成分析摘要
- AI 生成经营洞察
- 导出分析报告
- 保存分析项目

## 核心技术点

- Vue 3
- TypeScript
- Vite
- Pinia
- Vue Router
- Element Plus
- ECharts
- Web Worker
- 文件解析
- 虚拟滚动表格
- SSE / 流式输出
- 报表导出

## 简历亮点

可以写成：

> 构建 AI 数据分析平台，支持 CSV/Excel 数据解析、字段建模、图表自动生成、Dashboard 配置、AI 分析总结和报表导出，通过 Web Worker 和虚拟滚动优化大数据量渲染性能。

## 第一阶段计划

1. 搭建 Vue 3 + TypeScript 项目基础结构。
2. 实现文件上传和 CSV 解析。
3. 实现数据表格预览。
4. 实现字段类型识别。
5. 实现基础 ECharts 图表。
6. 实现 Dashboard 布局。
7. 实现本地保存分析项目。

## 第二阶段计划

1. 支持 Excel 文件解析。
2. 支持图表推荐。
3. 支持多图表联动。
4. 支持 Web Worker 解析大文件。
5. 支持 AI 流式分析摘要。
6. 支持报告导出。
7. 增加测试、文档和 CI。
